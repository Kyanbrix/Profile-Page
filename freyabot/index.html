    Privacy Policy

    Effective date: October 2, 2026

    This Privacy Policy explains what information the Freya Discord bot (the "Bot") collects, how it is used, and how you can have it deleted. The Bot is an unofficial fan project. It is not affiliated with or endorsed by Moonton or Discord.

    Summary

    • Hero stats commands (such as /hero, /top, /counters) store nothing about you.
    • If you use /login, the Bot stores your Discord user ID, your Mobile Legends ID (ML ID), your server (zone) ID and an encrypted login token from the game.
    • Your verification code is never stored.
    • Run /logout at any time to delete your stored login immediately.
    • The Bot does not read your messages, does not sell data, and does not use data for ads.

    1. Information the Bot collects

    1.1 When you use any command

    To answer a command, Discord sends the Bot your Discord user ID, the server and channel where you used it, and the options you chose (for example a hero name). The Bot uses this only to reply.

    • Temporary limits: your Discord user ID is held in memory for a few minutes to stop command spam. It is never written to disk and is cleared on restart.
    • Hero statistics: game data such as win rates and hero details is cached to reduce load on the data source. This cache contains public game data only, nothing about you.

    1.2 When you log in with /login (optional)

    Logging in is optional and only needed for account features such as /profile.

    DataWhyHow long it is kept
    Discord user ID To link the login to you Until your login ends (see below)
    ML ID and server ID To request the verification code and confirm it is your account Until your login ends
    A random login reference and timestamps To make each "Enter code" button single-use, to expire it after 10 minutes, and to limit how many codes can be requested Deleted automatically about 25 hours after the code was requested
    Login token from the game To fetch your profile when you ask for it Stored encrypted (AES-256-GCM) until your login ends

    Your login ends, and your stored login is deleted, when:

    • you run /logout;
    • the game's login token expires; or
    • the game rejects the token.

    Not stored:

    • Verification code: you type it into a private Discord pop-up. It is used once to log in and is never stored, logged or shown in chat.
    • Profile details (in-game name, level, rank, region, avatar): these are fetched from the game each time you use /profile. They are not saved.
    • Other account fields: the game's login response may include extra fields, such as an email address or phone number. The Bot ignores them and never stores or logs them.

    1.3 Logs

    The server keeps technical logs to fix errors and spot abuse. Logs may contain your Discord user ID together with events such as "logged in", "logged out" or "verification code sent". Logs never contain verification codes, login tokens or message content. They are rotated automatically and limited to a small fixed size, so older entries are deleted after a short time.

    2. How information is used

    Your information is used only to run the Bot's features:

    • to answer your commands;
    • to log you in and show your profile;
    • to prevent abuse, such as code spam to someone else's in-game mail.

    The Bot does not:

    • sell or rent your information;
    • use it for advertising or profiling;
    • share it except as described in section 3.

    3. Third parties

    The Bot relies on these services. Each has its own privacy policy.

    • Discord: delivers commands and replies.
    • Rone Arena API (arena.rone.dev): an unofficial community service that provides the game data.
      • When you log in, your ML ID, server ID and verification code are sent to it to complete the login.
      • When you use account features, your encrypted-at-rest login token is decrypted and sent to it to fetch your profile.
    • Moonton / Mobile Legends: Bang Bang: the game sends the verification code to your in-game mail and provides the account data.
    • Hosting provider: the Bot runs on a rented server (VPS), where the database and logs are stored.

    Images such as hero portraits are downloaded from the game's image servers. No information about you is included in those requests.

    4. Public replies

    Most account replies are private (only you can see them). The exception is /profile and the Post my profile button: they post your in-game name, ML ID, server, level, rank and avatar publicly in the channel, because you chose to share them. Hero statistics replies are also public.

    5. Security

    • Login tokens are encrypted at rest.
    • Secrets such as the encryption key are kept out of the code.
    • Account replies are private.
    • Each login button works only once, only for you, and only for 10 minutes.

    No system is perfectly secure, but the Bot is designed to keep as little data as possible.

    6. Your choices and rights

    • Delete your login: run /logout. Your stored login is deleted at once.
    • Don't log in: all hero statistics commands work without logging in.
    • Other requests: to ask what data is held about you, or to have any remaining data (such as log entries) deleted, contact the developer (section 9).

    7. Children

    The Bot is meant for users who meet Discord's minimum age requirement (at least 13, or older where local law requires it). It does not knowingly collect information from anyone younger.

    8. Changes to this policy

    This policy may be updated when the Bot changes. The latest version is always available in the Bot's repository, with the effective date at the top. Continuing to use the Bot after a change means you accept the updated policy.
